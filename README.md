# detec-o_de_anomalias_em_transa-es.py
Atividade proposta num bootcamp da DIO, onde devia otimizar um código para machine learning de detecção de anomalias em transações de cartões de crédito, testando diferentes balanceamentos de dados, modelos de machine learning e suas configs para sensibilidade aos dados enquanto mantém boa recall e precisão.
